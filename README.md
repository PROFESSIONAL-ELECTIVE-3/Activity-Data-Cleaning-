Requirements
PHP 8.2 or later (developed and tested on PHP 8.2.12, Windows)
PHP extensions: zip and simplexml (in php.ini, enable extension=zip)
A writable project folder (the script creates cleaned/)

How to Run
1. Make sure MMORS_water_quality_results_2012-2018_orig.xlsx is in the same folder as index.php.
2. From that folder, start PHP's built-in server:
3. Terminalbash
   php -S localhost:8000
4. Open http://localhost:8000/index.php in a browser.
